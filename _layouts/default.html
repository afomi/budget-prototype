Branch naming and document approval

main holds prototype code. budget/fy2025-26/approved holds the approved document version; budget/fy2025-26/working holds the next proposed version. Open a PR from working to approved. Merge means the document is approved. Future years use the same pattern, for example budget/fy2026-27/working. Work-in-progress belongs in a draft PR rather than another branch name.

WHERE VERIFICATION EARNS ITS PLACE

Git for review. A UTXO chain for selected evidence.

01 / START HERE

Anchor approved decisions

After approval, commit a document digest and references to the version, signers, and prior decision. Drafts and line-item discussions stay in Git and the review system.

02 / STRONGEST HANDOFFS

Trace authority through execution

Enacted appropriation → apportionment → allotment → obligation. A future application model could consume one state and create constrained successor states with an explicit remainder.

03 / KEEP THE BOUNDARY

Attest to payments

Link independently reconciled payment receipts to obligations. Treasury systems move money. A blockchain record supports verification of evidence.

UTXO model and open decisions

Represent budget authority in an application schema, with account, fiscal year, purpose, availability period, parent reference, and amount in integer cents. Keep native chain coins and transaction fees separate. Application rules must enforce amount conservation and inherited restrictions; UTXO consensus alone does not enforce budget law.

Approval, issuance, signer governance, correction events, privacy, off-chain evidence retrieval, and confirmation policy need to be defined for the selected chain. A signed append-only log may be sufficient if independent parties do not need a shared ledger.

Expiration and cancellation are different states. Existing obligations may be paid after the new-obligation period ends, subject to applicable rules. Legal approvals and trusted attestations still determine whether recorded events are valid.

Process references: OMB A–11 §10 · GAO budget terms · UTXO transactions. Blockchain placement is a design proposal.
